# 또 다른 나 · AI Replica Chat

합성 데이터로 소개, 승인 대기, 채팅, 자유문장 관계 관리 흐름을 검증하는 **localhost 전용 목 시제품**입니다. 실제 AI 응답이나 말투 학습 결과가 아닙니다.

## 실행

확인 환경: Node.js 24.14.1, npm 11.11.0. 추가 런타임 패키지와 DB 설치는 필요 없습니다.

```powershell
cd D:\Projects\ai-replica-chat
npm ci
npm run dev
```

브라우저: http://127.0.0.1:4317

```powershell
npm run typecheck
npm run lint
npm test
```

서버는 127.0.0.1에만 바인딩합니다. 명시적인 --demo 옵션이 필요하고 NODE_ENV가 production 또는 staging이면 시작을 거부합니다.

## 데모 흐름

1. 미등록 방문자: 소개와 승인 대기 화면. API도 자동 대화를 차단합니다.
2. 가상 친구 A / 가상 동료 B: 각자의 대화만 확인합니다. 새로고침 후에도 같은 서버 세션의 대화가 유지됩니다.
3. 소유자: 상대를 골라 관계를 자유로운 문장으로 작성하고 승인 여부를 변경합니다. 관계 숫자·친밀도 모드는 없습니다.
4. 승인 뒤 해당 데모 계정으로 전환하면 채팅할 수 있습니다. 새 세션 버튼은 그 계정의 대화만 초기화합니다.

데모 계정 선택은 **누구나 역할을 바꿀 수 있는 개발 편의 기능이며 보안 인증이 아닙니다.** 실서비스 사용자나 개인정보를 입력하지 마세요. 운영 인증이 구현되기 전 공개 배포할 수 없습니다.

## 데이터와 경계

모든 초기 인물·관계는 합성 예시입니다. 서버 메모리만 사용하며 재시작 시 초기화됩니다. 영구 DB, API 키, 모델, 카카오톡 데이터 연결은 없습니다. 과거 메신저 사실을 조회하지 않고 현재 계정의 현 세션만 목 응답기에 전달합니다.

사용자 원본/파생 데이터는 코드 폴더와 분리된 전용 로컬 위치에 유지합니다. 이 저장소에서는 읽거나 복사하지 않습니다. .env, 데이터셋, DB, 관계 설정 파일, 대화 로그, 캐시 등은 .gitignore로 제외합니다.

## 아직 미구현

운영 로그인·상대 식별, 실제 소유자 인증, 영구 저장·보존 기간, 승인 취소 정책, 모델 연결, 문맥 기반 말투 재현, 배포. 인증 설계가 정해졌다고 가정하지 않습니다.

코드 원격 대상은 byStander9/ai-replica-chat **PRIVATE**입니다. 개인 데이터와 로컬 보관 이력은 원격으로 전송하지 않습니다.
