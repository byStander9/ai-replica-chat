# 공개 코드와 로컬 전용 데이터

이 저장소는 공개 가능한 소스 코드, 합성 예시, 일반 요구사항, 테스트만 관리합니다. 저장소 공개는 웹앱 배포나 개인 데이터 공개를 뜻하지 않습니다.

## main에 포함할 수 있는 것

- 일반 개발 코드와 정적 화면
- 실제 인물을 나타내지 않는 합성 계정·관계·테스트 입력
- 개인 대화 인용이나 인물별 특성이 없는 요구사항 요약
- 개인정보를 포함하지 않는 실행·검증 문서와 의존성 잠금 파일

## 로컬에만 보존할 것

실제 메신저 원문과 파생 자료, 개인별 관계 설명, 대화 로그, DB, 환경 파일, 키, 사용자 대화 인용, 이러한 자료가 포함된 로컬 보관 이력은 공개 저장소에 보내지 않습니다.

Git 제외 규칙만으로 안전하다고 판단하지 않습니다. 푸시 전에 추적 파일 내용과 도달 가능한 커밋, 작성자 이메일, 메시지, 브랜치·태그를 확인합니다. 공개용 커밋에는 공개 계정명과 GitHub noreply 주소를 사용합니다.

로컬 보관 브랜치나 태그를 한꺼번에 전송하지 않습니다. 허용된 작업 브랜치만 목적지를 명시해 정상 푸시하며, 보관 이력을 공개하기 위한 강제 푸시는 하지 않습니다.

## 별도 작업

운영 인증, 모델/API 연결, 실제 데이터 처리, 보존 정책, 공개 배포와 라이선스 선택은 각각 별도 결정 사항입니다. 현재 앱은 localhost의 합성 목 시제품이며 운영 배포 차단을 유지합니다.
