# 서버 AI 연결과 합성 테스트 경계

## 모드와 데이터

기본 모드는 mock입니다. --synthetic-ai를 명시했을 때만 승인된 프로젝트 .env.local을 읽습니다. 시스템 환경이나 다른 프로젝트 파일에서 키를 검색하지 않습니다. 키는 서버의 비공개 필드에서 인증 헤더에만 사용하고, 클라이언트·응답·로그에 전달하지 않습니다.

키 파일은 일반 파일, 단일 링크, 심볼릭 링크가 아닌 경로, 워크스페이스 내부 경로여야 합니다. Git ignored와 미추적 상태 및 비어 있지 않은 단일 설정을 검사합니다. 키 생성·수정 코드는 없습니다.

현재 API 전송 허용 범위는 src/synthetic.ts에 정의된 합성 관계와 사용자 메시지뿐입니다. 임의 입력과 자유문장으로 수정한 관계는 전송하지 않습니다. 실제 인물의 말투 학습이나 메신저 데이터 처리는 포함하지 않습니다.

현재 계정의 현재 세션만 입력에 포함합니다. 다른 계정의 대화나 관계는 응답기에 전달하지 않습니다. 도구·파일·검색 기능은 요청하지 않습니다.

## 요청 처리

상대와 방의 조합마다 하나의 요청만 진행합니다. 동일 상대·동일 방·동일 요청 ID·동일 입력은 진행 중에도 같은 작업을 기다리며, 완료 후에도 새 외부 호출을 만들지 않습니다. 같은 ID로 다른 입력을 보내면 409입니다.

성공한 입력과 응답만 한 번에 세션에 반영합니다. 오류·시간 초과 시 반영하지 않습니다. 관리자 관계 변경·승인 취소 뒤 도착한 응답도 폐기합니다. 처리 중 세션 초기화는 차단합니다.

요청 기록은 서버 메모리 안에서만 유지합니다. 서버 재시작 뒤까지 영구적인 exactly-once 또는 과금 취소를 보장하지 않습니다. 시간 초과 후 추가 외부 호출을 잠그며 임의 자동 재시도나 모델 교체를 하지 않습니다.

## 외부 요청과 오류

- 공식 https://api.openai.com/v1/responses 주소 고정. 환경 변수로 다른 엔드포인트를 받지 않음
- 모델 gpt-6-luna, reasoning effort none, max_output_tokens 256, store false
- 서버당 최대 3회 시도, 20초 제한. HTTP 리다이렉트 불허
- 401/403은 인증·접근 오류, 429는 쿼터·요청 한도 오류로 안전하게 표시
- 알려진 insufficient_quota / rate_limit_exceeded 코드만 고정된 로컬 코드로 변환. 원문 오류 메시지는 반환하지 않음
- 인증·접근·429·시간 초과 뒤에는 추가 호출 중단
- 불완전·빈 응답·거절 전용·잘못된 JSON은 정상 AI 답변으로 보관하지 않음
- client fetch는 60초 제한. 실패 후 요청 ID를 유지하고 상태 GET만 수행하며 전송을 자동 반복하지 않음

store false는 응답 저장 제어이며 조직의 Zero Data Retention 설정과 동일하지 않습니다. 현재 실제 개인 데이터 전송은 허용되지 않습니다.

## 검증

npm test는 실제 키 없이 가짜 토큰·로컬 HTTP 목으로 처리합니다. npm run test:live는 별도 승인된 실제 합성 검증이며, 최대 2회와 첫 실패 즉시 중단을 적용합니다. 실제 실행 결과와 계정별 제한 상태는 공개 문서나 코드 로그에 넣지 않습니다.
