# 로컬 데모의 권한 경계

## 현재 구현이 보장하는 범위

- 서버 바인딩은 127.0.0.1 고정입니다. 호스트와 Origin을 검증하고 교차 사이트 API 요청을 거부합니다. 소개 페이지의 정상 탐색은 허용합니다.
- 데모 헤더에서 선택한 신원을 기준으로 미승인 채팅과 비소유자의 관계 조회·수정을 서버가 차단합니다.
- 각 계정의 관계와 현 세션만 목 응답기에 전달합니다. 요청 본문으로 다른 계정 ID를 지정할 수 없습니다.
- 일반 채팅 문자열은 명령으로 실행하지 않습니다. 관계 수정 경로와 채팅 경로가 분리되어 있습니다.
- 임의 파일 경로를 제공하지 않고 정적 파일 3개만 제공합니다. 실제 데이터 디렉터리는 경로 매핑에 없습니다.
- 본문 크기, 관계·메시지 길이, 현 세션 횟수를 제한합니다. 대화 내용의 서버 로그를 남기지 않습니다.
- 사용자 문장은 HTML로 삽입하지 않습니다. CSP와 no-store를 적용합니다.

## 운영 인증을 대신하지 않는 부분

X-Demo-Identity는 개발 편의를 위한 역할 선택입니다. 로컬 사용자는 소유자 역할도 선택할 수 있습니다. 이를 인증이나 공격 방어가 완성된 서비스로 취급하면 안 됩니다. 실사용자 초대 토큰이나 영구 자격 증명을 만들지 않습니다.

시작 시 --demo를 강제하고 production/staging 환경을 거부합니다. 이 차단을 제거하고 서버를 공개하는 작업은 이번 범위에 없습니다. 실제 인증·인가·소유자 권한·세션 수명·보존 정책을 설계하고 검증해야 운영으로 전환할 수 있습니다.

목 응답기는 현재 UI/데이터 흐름만 보여줍니다. 미래 모델의 프롬프트 공격 방어 또는 개인정보 제거가 검증되었다는 뜻이 아닙니다.
